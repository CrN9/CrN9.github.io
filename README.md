# Сайт Александра Смирнова

Личный сайт-портфолио. React + Vite + JavaScript, three.js для модели машины, GSAP
для её движения по странице.

## Установка

Нужен Node.js 24.15 (версия зафиксирована в `.nvmrc`):

```bash
nvm use
npm install
```

## Запуск

```bash
npm run dev       # локальный сервер с горячей перезагрузкой
npm run build     # production-сборка в dist/
npm run preview   # посмотреть собранный dist/
```

Ещё есть `npm run lint` (ESLint) и `npm run prettier` (форматирование).

## Как править тексты

Всё содержимое сайта лежит в одном файле — **`src/data/content.js`**. Вёрстку и
стили при этом трогать не нужно.

| Что менять                                   | Где                                  |
| -------------------------------------------- | ------------------------------------ |
| Имя, роль, город, почта                      | `person`                             |
| Заголовок и подпись в шапке                  | `hero`                               |
| Названия остановок в оглавлении              | `stops`                              |
| Абзацы «Кто я»                               | `intro`                              |
| Проекты: название, описание, стек, роль      | `projects.items`                     |
| Ступени прогрессии в «Пассажирском маршруте» | `projects.items[…].chart`            |
| Показатели дипломной работы                  | `projects.items[…].results`          |
| Навыки                                       | `skills.groups`                      |
| Образование и языки                          | `education`                          |
| Контакты                                     | `contacts`, почта — в `person.email` |

Метки `ЗАПОЛНИТЬ` в комментариях помечают места, которые ещё ждут текста.

## Картинки и модель

- Скриншоты проектов — `public/images/`. Путь и размеры прописываются в `images`
  у проекта в `content.js`; ширина и высота нужны, чтобы страница не прыгала при
  загрузке.
- Модель машины — `public/models/car.glb`, 488 КБ. Исходник лежит в
  `resources/car_game/`. Если модель обновится, её нужно пережать:

  ```bash
  npx @gltf-transform/cli optimize resources/car_game/car_model.glb \
    public/models/car.glb --compress meshopt --simplify true \
    --simplify-error 0.0005 --texture-compress false
  ```

## Деплой

Содержимое репозитория попадает в `CrN9.github.io` и публикуется
на GitHub Pages воркфлоу `.github/workflows/deploy.yml`: он собирает
проект и выкладывает `dist/`. Срабатывает на push в `main` или `master`
и вручную из вкладки Actions.

Один раз в настройках репозитория нужно выставить
**Settings → Pages → Source → GitHub Actions**, иначе сборка будет
проходить, а сайт не обновится.

## Что стоит знать

- Тема одна — тёмная. Светлой версии нет намеренно.
- Цвета остановок и полос графиков заданы переменными в начале `src/index.css`
  (`--c1`…`--c5`, `--r1`…`--r7`). Контраст текста проверен, минимум — 4.5:1; при
  смене цветов это стоит перепроверить.
- Машина едет между двумя якорями в разметке: `data-car-anchor="hero"` в шапке и
  `data-car-anchor="project"` внутри «Пассажирского маршрута». На узких экранах
  на перегоне она не показывается — слева нет места.
